## AI draft

The draft used RET-2024.

## RET-2026 — active returns policy

Effective January 1, 2026.

1. Return requests must be made within 30 days of purchase.
2. Items must be unused and accompanied by a receipt.
3. The store reviews each request before approving a refund. This policy is
   not an approval for any individual purchase.

## RET-2024 — archived returns policy

Replaced by RET-2026.

1. Return requests must be made within 60 days of purchase.
2. Items must be unused and accompanied by a receipt.
3. The store reviews each request before approving a refund. This document
   is retained for reference and no longer governs new requests.
