# Check the answer before you use it

Garrett Johnson AI · Foundations worksheet

Use this with an AI draft, recommendation, or claimed action. An answer sounding
confident is not evidence that the information is current or the job is done.

## 1. Define the job

- What did you actually ask for?
- What outcome would count as success?
- What constraints or approvals apply?

## 2. Inspect the evidence

- Which exact source supports the important claim?
- Is it the current version? Does it apply to this customer, location, or case?
- Does the source say what the assistant says it does?
- What is unknown or missing?

## 4. Decide

[ ] Use it: supported, applicable, and verified.
[ ] Correct it: evidence exists but the answer or action is wrong.
[ ] Pause: evidence is insufficient; ask a person or obtain more information.

## Fictional worked example

An assistant drafts “Returns are accepted within 60 days,” citing an archived
2024 policy. The current 2026 policy says 30 days. Correct the answer using the
current policy, cite it, and check whether the customer's situation is covered.
Improving the tone of the original answer would not fix the error.
